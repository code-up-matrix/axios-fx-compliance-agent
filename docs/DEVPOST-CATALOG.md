## Evidence and implementation map

The machine-readable source is `data/devpost-catalog.json`; each entry distinguishes directory-only evidence from rules/overview review. The interactive board at `/lab/catalog` supports search and readiness filters. The directory count changed from 52 to 51 as OpenCV expired. Detailed source requirements and demo plans are separate from implementation status.

The seven implemented web modules are FieldBrief, CultureRoute, CrowdQuest, FitReceipt, ReLoop, LessonScript and RhythmWeave. PayProof was implemented earlier in this repository. HandoverShelf is a native Uliya package. Other rows are scoped concepts awaiting rules, eligibility, native-platform access or upstream contribution work; they are not finished apps or new repositories.

See `DEVPOST-DEPLOYMENT.md` for the concrete access and integration blockers. No final registration or submission was made.
