# HandoverShelf · UGREEN Round 1

An evidence-linked project handover Skill for Uliya on UGREEN AI NAS. The package uses the official 0.7.3 starter kit's capability catalog 2.0.0: file-agent discovery, document-agent extraction/reconciliation, and an optional knowledge-agent save with the platform's approval flow.

Submit the separate proposal PDF and the ZIP under `releases/`, after checking the final organizer requirements and completing your own participant declarations. The ZIP contains only `SKILL.md` and `references/`. It has no scripts, runtime binaries or undeclared external service.

Validation: run the official starter kit's `scripts/check-skill.mjs native/handovershelf/handover-shelf`. The generated report is included under `verification/`. A static checker pass is not proof of NAS installation or execution. Real-device tests remain pending the finalist environment.
